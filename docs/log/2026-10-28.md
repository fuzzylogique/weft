# Design log, 2026-10-28

First working day. Everything below was built in one session from the research
doc ("Protocol Emulator ASIC: How to Start"), with AI assistance; this entry is
the honest record the doc asks for.

## Decisions (see docs/adr)

- Simple single-cycle 16-bit core plus timing hardware (bit timer with WAITT,
  edge waits, cycle counter, CRC unit), not a PIO clone. ADR-001.
- 128 x 16 flop program memory, host loaded, not reset. ADR-002.
- SPI target host port on `ui_in[7:5]`/`uo_out[7]` with load/run/stop/step/
  push/pull/peek. ADR-003.
- 16-bit encoding, 4-bit opcode, 8 registers, one link register. ADR-004.

## What exists

- `sw/weft/isa.py` single-source ISA table; `weft.gen` writes the Verilog
  constants and `docs/isa.md`.
- Assembler with labels, `.equ`, expressions, pseudo-ops, disassembler.
- Cycle-accurate ISS mirroring the RTL's commit structure.
- Firmware: blink, selftest, uart_tx, uart_rx, spi_master, i2c_master.
- RTL: core, regfile, pmem, fifo, timer, crc, sync, host SPI, TT top. Lint clean.
- 53 Python tests (Hypothesis round trips, ISS semantics, firmware on the ISS
  with UART/SPI/I2C models and ASCII snapshots).
- cocotb suite: host port tests, lockstep RTL-vs-ISS for every program and for
  random programs, PEEK comparison of all state at the end of each run.
- Yosys with the CMOS5L liberty: 9,462 cells, 225,536 µm² (41% of the 6x4
  budget at 60% density); program memory is 74% of that.
- cocotb: 12 of 12 passing under Verilator (every program and 12 random
  programs in lockstep with the ISS, state compared through PEEK at the end).
- Formal, through Yosys's SAT engine: core 8-cycle BMC passes for every
  instruction stream; the program-level UART proof passes at BIT=4; timer and
  FIFO bounded checks pass (induction still needs invariants).

## Bugs found and the test that now catches them

| Symptom | Root cause | Test |
| --- | --- | --- |
| Hypothesis found a legal word that `decode` called undefined | descriptors required unused fields to be zero; hardware ignores them | `test_every_word_is_legal_or_illegal_consistently` |
| blink's two half periods differed by one cycle | second half has one more instruction (JMP) | `test_blink_period_exact` |
| UART TX and SPI firmware "failed" on the ISS | the lockstep marker word shifted every absolute branch target by one | `assemble(..., base=1)`; all `test_programs.py` |
| SPI target model skipped a response byte | model consumed a byte on the chip-select glitch at reset (CSn resets low) | `test_spi_master_mode0` |
| UART decoder saw a false start bit at reset | TX is low until the first instruction raises it | decoder now needs idle-high first |
| Every lockstep run drifted by ~15 cycles | the RUN command's trailing idle wait let the core start before the marker watch began | `host.run_hold()` returns at the command's last clock edge |
| TCNT and the tick flag differed after STOP | the RTL timer kept counting while the core was stopped | timer now advances only with the core enable (STOP freezes it, STEP moves it one cycle); ISS, docs and the timer proof updated |
| UART program proof refuted at BIT=3 | the per-bit loop is OUTC, DJNZ, SHRC plus WAITT: four cycles minimum | proof runs at BIT=4; documented as the program's minimum period |
| Timer proof base case failed at step 4 | the wrapper's "cycles since TSET" counter started one cycle late | counter starts at 1 in the cycle after TSET |
| CI (Icarus) failed random seed 3 that Verilator passed | the host port counted bytes in 8 bits, so a 258-byte full-memory LOAD wrapped and never wrote word 127; Verilator read the unwritten word as 0 (NOP), Icarus as X and the core stalled on it when seed 3 ran off its end | host state machine rewritten with per-transaction flags, no counter; `test_load_last_word` loads a HALT into word 127 |

## Timing: reading the slow-corner slack and shortening the path

From the gds run's `metrics.csv`: slow corner worst setup slack -2.68 ns, TNS
-152 ns, 119 endpoints, 6 max-slew violations; nominal +5.76 ns; fast +10.68 ns.
Yosys's longest topological path (`ltp` on the liberty-mapped netlist with the
flops removed) was 38 cells: `pc` -> 128:1 read mux -> `instr` -> operand
address decode -> register read -> adder -> write-back mux -> register file.

Changes, all firmware-invisible (ADR-005): registered instruction fetch from
the next PC (`weft_pmem` read port is now registered), three register-file read
ports with no decode in front of them, DJNZ deciding on `a != 1`, and a 13 ns
implementation clock with signoff fixed at 20 ns (`src/signoff.sdc`). Longest
path now 29 cells. Verified before pushing: Verilator lint clean, 13 of 13
cocotb lockstep tests, core 12-cycle bound and covers (local sby with z3),
Yosys area 227,964 µm² (41.5%, +1,674 µm²).

## Decisions made during verification

- The bit timer and cycle counter freeze when the host STOPs the core and
  advance one cycle per STEP. Without this, single-stepping a program that uses
  WAITT would see ticks arrive between steps.
- `uart_tx.asm` needs a bit period of at least 4 cycles (12.5 Mbaud at
  50 MHz). The formal proof found this; it is now stated in the program.
